# Demo Datasets

This folder contains deterministic CSV demo datasets generated by DataBoom's Generator-Boom suite.

Current demos:

- `bank-o-boom/csv`: Bank-O-Boom banking-style customers, accounts, and transactions.
- `health-boom/csv`: Health-Boom patients, encounters, and vitals.

These datasets are synthetic and should not be treated as real customer or patient data.

Regenerate Bank-O-Boom demo data:

```bash
.venv/bin/databoom generate demo/bank-o-boom/schema.sql \
  --output-dir demo/bank-o-boom/csv \
  --rows customers=100 \
  --rows bank_accounts=250 \
  --rows transactions=750 \
  --format csv \
  --domain financial \
  --seed demo-bank-o-boom
```

Regenerate Health-Boom demo data:

```bash
.venv/bin/databoom generate demo/health-boom/schema.sql \
  --output-dir demo/health-boom/csv \
  --rows patients=300 \
  --rows encounters=500 \
  --rows vitals=500 \
  --format csv \
  --domain healthcare \
  --seed demo-health-boom
```
