# Demo Datasets

This folder contains deterministic CSV demo datasets generated by DataBoom.

Current demos:

- `financial-relational/csv`: Table-Boom banking-style customers, accounts, and transactions.
- `healthcare-relational/csv`: Table-Boom patients, encounters, and vitals.

These datasets are synthetic and should not be treated as real customer or patient data.

Regenerate the financial relational demo data:

```bash
.venv/bin/databoom generate demo/financial-relational/schema.sql \
  --output-dir demo/financial-relational/csv \
  --rows customers=100 \
  --rows bank_accounts=250 \
  --rows transactions=750 \
  --format csv \
  --domain financial \
  --seed demo-financial-relational
```

Regenerate the healthcare relational demo data:

```bash
.venv/bin/databoom generate demo/healthcare-relational/schema.sql \
  --output-dir demo/healthcare-relational/csv \
  --rows patients=300 \
  --rows encounters=500 \
  --rows vitals=500 \
  --format csv \
  --domain healthcare \
  --seed demo-healthcare-relational
```
