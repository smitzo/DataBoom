# Demo Datasets

This folder contains deterministic CSV demo datasets generated by Boom Data.

Current demos:

- `financial/csv`: banking-style customers, accounts, and transactions.
- `healthcare/csv`: patients, encounters, and vitals.

These datasets are synthetic and should not be treated as real customer or patient data.

Regenerate financial demo data:

```bash
.venv/bin/boom-data generate demo/financial/schema.sql \
  --output-dir demo/financial/csv \
  --rows customers=100 \
  --rows bank_accounts=250 \
  --rows transactions=750 \
  --format csv \
  --domain financial \
  --seed demo-financial
```

Regenerate healthcare demo data:

```bash
.venv/bin/boom-data generate demo/healthcare/schema.sql \
  --output-dir demo/healthcare/csv \
  --rows patients=300 \
  --rows encounters=500 \
  --rows vitals=500 \
  --format csv \
  --domain healthcare \
  --seed demo-healthcare
```
